ℹ️ About BLOCK MASTER

An original block puzzle game built with HTML5, CSS and JavaScript. All art, sounds and code are original — made with the Web Audio API and CSS, no external assets.

Privacy: everything (scores, coins, settings) is stored only in your browser's local storage on this device. Nothing is collected, tracked or sent anywhere. No account, no ads, no purchases.

How scoring works: 1 point per cell placed · 10 / 30 / 60+ bonus for 1 / 2 / 3+ simultaneous lines · combo multiplier for consecutive clears · +100 for clearing the whole board.
